# 職務交接表（Leave & Job Handover Form）

請假時填寫的職務代理交接表單，純靜態網頁，無任何外部依賴。

## 檔案結構

| 檔案 | 內容 |
| --- | --- |
| `index.html` | 表單結構 |
| `style.css` | 樣式（主題色集中在 `:root` 的 CSS variables） |
| `script.js` | 交接事項列的新增／刪除／編號，與個人資訊的 localStorage 自動保存 |

## 使用方式

直接用瀏覽器開啟 `index.html`（或 `open index.html`），填寫後按「🖨️ 列印 / 匯出」即可列印或另存 PDF，再進行電子簽名。

## 內容區塊

1. 請假人基本資訊（姓名、部門、假別、起訖日）
2. 職務代理人資訊（含 Slack ID、Email）
3. 工作交接事項（可動態新增／刪除列，預設 3 列）
4. 緊急聯絡方式
5. 簽核欄（申請人、職務代理人）

列印時會自動隱藏新增／刪除／列印按鈕（`@media print`）。

## 自動保存

「一、請假人基本資訊」「二、職務代理人資訊」「四、緊急聯絡方式」的全部欄位會透過 localStorage 自動保存，下次開啟自動帶入；「三、工作交接事項」與「五、簽核欄」屬每次不同的內容，不保存。
